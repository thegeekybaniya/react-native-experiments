# React Native Playground

This is my personal playground for trying out new things in React Native. Here you'll find a bunch of small experiments and UI prototypes—mostly focused on gestures, animations, and fun interactions. I use this repo to learn, test ideas, and play with new libraries.

---

## How to Run

1. **Clone this repo**
   ```bash
   git clone https://github.com/your-username/react-native-experiments.git
   cd react-native-experiments
   ```

2. **Install dependencies**
   ```bash
   npm install
   # or
   yarn install
   ```

3. **Start the dev server**
   ```bash
   npm start
   # or
   yarn start
   ```

4. **Run on your device or simulator**
   ```bash
   # iOS
   npm run ios

   # Android
   npm run android

   # Web (optional)
   npm run web
   ```

## Experiments

- **Drag & Zoom**  
  Drag and pinch-zoom any content with smooth springy animations.

- **Swipe Cards**  
  Tinder-style swipeable cards with animated exits and feedback.

- **Card Deck**  
  Animated stack of cards that cycles from top to bottom with depth and scaling.

- **Three Cup Monte**  
  Classic shell game with animated cup shuffling and ball tracking.

- **Three Cup Monte 3D**  
  Enhanced shell game with curved, 3D-like cup movement.

- **Drawing Canvas**  
  Simple drawing app with color/brush selection and persistent storage.

- **Analog Clock**  
  Interactive analog clock with real-time updates and manual time setting via gestures.
